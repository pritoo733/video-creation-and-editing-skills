# Editing Preflight

Run this before installing tools, choosing an editor, or making edits to supplied footage. Tailor it to the task; do not make setup work larger than the edit.

## Inspect the source and request

- Confirm which files are originals, which are current edits, and which should appear in the final cut.
- Check that each source opens; record duration, dimensions, frame rate, orientation, audio streams, sample rate, and channels when tools allow.
- Identify the intended destination and its current format requirements when those requirements matter.
- Ask which details must stay intact: quotes, chronology, faces, brand elements, source audio, cuts, disclosures, or particular scenes.
- Check storage and any required codecs, fonts, plugins, models, and export features before depending on them.

## Choose the lowest-risk workable path

- Prefer tools already available when they meet the brief. Verify versions and actual platform support instead of assuming an integration will work.
- If installation is needed, explain what it installs and where; do not silently change the user's environment.
- Preserve untouched media. Work on a copy or in a reversible, editable timeline and keep original timestamps in the edit notes.
- Before external analysis, transcription, translation, generation, or rendering, state what media will leave the device and obtain authorization. For paid work, state known prices or uncertainty and the smallest useful pilot first.
- If a capability is missing, report that early and continue any independent edit planning or local checks that remain possible.

## Prepare a reviewable edit

Create a short edit decision list with source IDs, in/out timecodes, intended action, reason, caption/narration dependencies, and any masking. Make a small representative edit when applying a new treatment. Inspect the preview at its intended viewing size and resolve sync, crop, and readability issues before editing the rest. Keep the render command/settings and output paths with the project so the result can be reproduced.
