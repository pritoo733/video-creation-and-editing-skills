# Editing Instructional Videos

Make changes against the user's current edit goal, preserve meaning and source evidence, and deliver a reviewed export with enough edit data for later revisions. Read [the review checklist](references/review-checklist.md) for the full quality gate. Read [the local rendering guide](references/local-rendering.md) when using Piper, FFmpeg, or a frame-based local workflow.

## Edit contract

Before editing, identify the current source and final version, requested changes, audience, destination format, and any protected wording or shots. Keep originals. Record the requested changes and affected scenes in a concise edit manifest or existing editor timeline.

For narration changes, preserve the speaker's intended meaning and claims. Regenerate captions from the revised audio timings. For screenshot edits, use genuine source captures and document masking or cropping. Keep important app labels, disclaimers, watermarks, and context legible.

Make a representative scene change first when the edit introduces a new treatment. Review the candidate at full playback size before applying it across the timeline. Use local tools where available; do not submit paid or external processing without the needed authorization.

## Delivery gate

Deliver only the current export. Verify that it opens, has the expected duration, dimensions, frame rate, and audio/caption streams, and that the final words are complete. Review the rendered result for visual continuity, caption sync/readability, voice quality, sensitive content, and compliance with the requested treatment. State which checks were performed and which were unavailable. Do not equate a successful render or codec check with a creative review.
